# Contributing to Customer Focus – Success Experience Engine Console

Thank you for your interest in contributing to the **Customer Focus Engine Console**.  
This project supports Client Partners, Delivery Leaders, and Success Managers by providing a unified, offline insights engine for delivery excellence and renewal strategy.

This guide explains how to contribute effectively and consistently.

---

## ⭐ How to Contribute

### 1. Reporting Issues
If you find a bug, inconsistency, or documentation gap:

- Open an Issue in GitHub  
- Include:
  - Clear description of the problem  
  - Steps to reproduce  
  - Expected vs. actual behavior  
  - Screenshots (if applicable)  
  - Excel file examples (if relevant)

---

### 2. Suggesting Enhancements
Enhancement ideas are welcome. Examples:

- New engine logic  
- Additional roll‑ups  
- Better Excel templates  
- Documentation improvements  
- UI/UX refinements  

Before submitting, check existing Issues to avoid duplicates.

---

### 3. Adding New Features
If you want to add a new feature:

1. Open an Issue titled **Feature Proposal: <name>**  
2. Describe:
   - What problem it solves  
   - Why it matters  
   - Expected inputs/outputs  
   - Any new Excel templates required  

Once approved, you may proceed with a Pull Request.

---

## ⭐ Pull Request Guidelines

### ✔ Branch Naming
Use clear, consistent branch names:

```
feature/<short-description>
fix/<short-description>
docs/<short-description>
```

Examples:
```
feature/renewal-score-improvements
fix/stakeholder-sentiment-bug
docs/update-architecture-page
```

---

### ✔ Commit Messages
Use meaningful commit messages:

```
Add Delivery Health scoring logic
Fix SLA calculation for ticket velocity
Update README with architecture diagram
```

Extended descriptions are optional but encouraged.

---

### ✔ Pull Request Requirements
Every PR must include:

- Purpose of the change  
- Summary of modifications  
- Screenshots (if UI or output changed)  
- Updated documentation (if needed)  
- Confirmation that Excel templates still validate  

PRs should be small and focused.

---

## ⭐ Documentation Contributions

Documentation lives in the **GitHub Wiki**.

You may contribute by improving:

- Engine descriptions  
- Architecture diagrams  
- File specifications  
- User Guide  
- Developer Guide  
- FAQ  
- Roadmap  

Before editing the Wiki, ensure your changes align with the project’s structure and tone.

---

## ⭐ Excel Template Contributions

If you propose changes to the six Excel templates:

- Maintain column naming consistency  
- Do not remove required fields  
- Add new fields only when justified  
- Update the File Specifications page accordingly  
- Provide sample data for testing  

---

## ⭐ Code of Conduct

All contributors are expected to:

- Be respectful and constructive  
- Avoid personal attacks  
- Provide clear, actionable feedback  
- Collaborate openly  

This project values professionalism and clarity.

---

## ⭐ Questions?

If you have questions about contributing, open an Issue titled:

```
Question: <your topic>
```

We’ll respond promptly.

Thank you for helping strengthen the Customer Focus Engine Console.
